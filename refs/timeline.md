# 淮海战役阶段态势与时间线（1948-11-06 至 1949-01-10）

> 说明：本文只整理客观事实（时间、番号、大致位置、结果），不复制任何受版权保护的叙述文字与图面。数字凡有口径差异均并列标注；无法核实者标“未核实/估算”。坐标见 [geo.json](./geo.json)，来源编号见 [sources.md](./sources.md)。

## 总览

- **时间**：1948-11-06 至 1949-01-10，共 66 天。
- **解放军**：约 60 万人（华东野战军 40 余万人、中原野战军约 12–15 万人、华东/中原军区地方部队及冀鲁豫军区一部）。
- **国民党军**：约 80 万人（徐州“剿总”刘峙集团 5 个兵团及多个绥靖区，加华中“剿总”黄维第十二兵团）。
- **指挥**：解放军总前委刘伯承、陈毅、邓小平、粟裕、谭震林（邓小平为书记）；国民党军徐州“剿总”总司令刘峙，副总司令杜聿明（战役后期实际指挥）。
- **结果**：歼国民党军 55.5 万余人；解放军伤亡 13 万余人（口径差异见下）。

## 第一阶段：围歼黄百韬兵团（1948-11-06 至 11-22）

| 项目 | 内容 |
|---|---|
| 核心包围点 | 碾庄（碾庄圩），今江苏邳州碾庄镇 |
| 包围圈 | 以碾庄圩为中心，南北约 3 km、东西约 6 km（亲历者回忆，来源 S25） |
| 阻援 | 大许家—麻谷子一线徐东阻击战（11-12 至 11-22），阻邱清泉第二兵团、李弥第十三兵团东援 |
| 切断退路 | 曹八集（11-09 前后）；中野第三纵队 11-15 攻克宿县，切断徐州—蚌埠 |
| 起义 | 11-08 何基沣、张克侠率第三绥靖区部队在贾汪、台儿庄起义，约 2 万余人 |
| 侧翼战斗 | 11-08 至 11-12 华野第一纵队在窑湾歼第63军约 1.37 万人 |
| 解放军参战 | 华野主力（山东兵团第7、9、13纵及鲁中南纵队等为围歼主力；第1、4、6、8、11纵等参加追击与阻援），中野主力配合 |
| 国民党军 | 第七兵团（黄百韬）：第25、63、64、100军及第44军等，约 10 万–12 万人（口径不一） |
| 结果 | 11-22 全歼第七兵团约 10 万余人；黄百韬自杀/阵亡（死因口径不一） |

**时间线**

| 日期 | 事件 |
|---|---|
| 11-06 | 华东野战军分路南下，战役发起 |
| 11-07 | 黄百韬兵团自新安镇沿陇海线西撤 |
| 11-08 | 何基沣、张克侠起义；华野追击部队直插曹八集 |
| 11-08 至 11-12 | 窑湾战斗，第63军被歼 |
| 11-11 | 黄百韬兵团 4 个军被合围于碾庄圩地区 |
| 11-12 至 11-22 | 徐东阻击战；碾庄逐村争夺 |
| 11-15 | 中野第三纵队攻克宿县 |
| 11-22 | 碾庄全歼，黄百韬兵团覆灭 |

## 第二阶段：双堆集围歼黄维兵团（1948-11-23 至 12-15）

| 项目 | 内容 |
|---|---|
| 核心包围点 | 双堆集，今安徽淮北濉溪县双堆集镇 |
| 包围圈 | 11-25 完成包围，纵横约 7.5 km；最后阶段被压缩在双堆集、大小马庄、杨子秀庄等东西不足 3 华里的狭长地区（S15、S01） |
| 阻援 | 蚌埠—固镇以北，阻李延年第六兵团、刘汝明第八兵团北援；涡河、浍河一线节节阻击黄维东进 |
| 解放军参战 | 中原野战军全部（第1、2、3、4、6、9、11纵）及华野一部（第3、7、13纵及特纵等） |
| 国民党军 | 第十二兵团（黄维，副司令胡琏、吴绍周）：第10、14、18、85军等，约 10 万–12 万人（口径不一） |
| 结果 | 12-15 全歼第十二兵团约 10 万余人；黄维、吴绍周被俘 |

**时间线**

| 日期 | 事件 |
|---|---|

| 11-25 | 中野将黄维兵团包围于双堆集地区 |
| 11-27 | 第85军第110师师长廖运周率部起义 |
| 12-05 | 总前委下达总攻命令 |
| 12-06 | 大王庄血战，华野七纵、中野六纵等争夺双堆集南侧屏障 |
| 12-15 | 全歼第十二兵团，生俘黄维、吴绍周 |

## 第三阶段：陈官庄围歼杜聿明集团（1948-12-16 至 1949-01-10）

> 包围行动始于 12-04；12-16 起为正式第三阶段（围困与总攻）。

| 项目 | 内容 |
|---|---|
| 核心包围点 | 陈官庄，今河南永城陈官庄镇（乡） |
| 包围圈 | 陈官庄、青龙集、李石林地区，南北约 5 km、东西约 10 km（S01、S11） |
| 前奏 | 11-30 杜聿明率第二、十三、十六兵团等约 30 万人放弃徐州西撤；12-01 徐州弃守；12-04 华野 11 个纵队完成包围 |
| 阻援/堵击 | 郭楼（陈官庄东南约 2 km）为南突必经之地，华野第二纵队等组织纵深防御；鲁楼为华野第十纵队阵地（位置未核） |
| 解放军参战 | 华野 11 个纵队（第1、2、3、4、8、9、10、11、12纵及特纵等）；中野一部监视蚌埠 |
| 国民党军 | 杜聿明集团：第二兵团（邱清泉）、第十三兵团（李弥）、第十六兵团（孙元良），约 30 万人（含机关、随军人员） |
| 结果 | 1949-01-10 全歼第二、十三、十六兵团等约 20 万人；杜聿明被俘，邱清泉被击毙，李弥等少数人逃脱 |

**时间线**

| 日期 | 事件 |
|---|---|
| 11-30 | 杜聿明集团放弃徐州西撤 |
| 12-01 | 徐州弃守 |
| 12-04 | 华野 11 个纵队将杜聿明集团包围于陈官庄、青龙集、李石林地区 |
| 12-06 | 孙元良第十六兵团突围，被全歼 |
| 12-19 至 12-28 | 大雪，空投中断，包围圈内粮弹断绝，1 万余人投降 |
| 1949-01-06 | 华野发起总攻（约 15:30） |
| 1949-01-10 | 全歼杜聿明集团；杜聿明被俘，邱清泉被击毙，李弥逃脱 |

## 不能支撑的部分（与时间线相关）

- **逐日战线**：只有阶段级态势与少数关键日事件，没有逐日交战线。
- **逐团位置**：兵团/军级可靠，师级部分可靠，团级仅窑湾、大王庄、郭楼等少数点名战斗。
- **精确伤亡分项**：毙伤俘、起义、投诚的细分数字口径不一，未逐项核实。
- **国民党军精确兵力**：各兵团“10 万/12 万/30 万”多为概数，含非战斗人员，不能当作战斗兵员数。
- **天气逐日**：仅 12-19 至 12-28 大雪等少数明确记载。
